애프터마켓 주요 제도 [확인]

- 가격제한폭: 정규장과 동일하게 **당일 기준가(=전일 정규장 종가) ±30%**. 기존 시간외 단일가(당일 종가 ±10%)와 기준이 다르다.
- 호가: 지정가, 최우선지정가, 최유리지정가만 허용하고 시장가는 허용하지 않는다.
- VI(변동성완화장치), 공매도 규제는 정규장과 동일하게 적용한다.
- 거래 대상: ETF·ETN은 제외한다. 관리종목·투자경고/위험종목 등 일부를 제외한 상장주식 대부분이 대상이다.

## 2. 종가의 기준 (공식 정의)

### 2.1 KRX 공식 입장 [확인]

- **종가 = 15:30경 정규시장 종료 시 형성되는 최종가격**이며, 애프터마켓 개설 이후에도 변하지 않는다.
- 애프터마켓 종료(20:00) 시점의 가격은 종가가 아니다.
- 거래소(코스닥시장본부 등)는 개설 나흘 만인 2026-09-17 상장사에 "애프터마켓 개설 이후 종가 유의 안내"를 발송했다.
  - 목적: 시가총액 산정, 추가상장 수수료 산정 등 종가 기반 상장·공시 업무에서 애프터마켓 가격을 잘못 적용하는 오류를 방지한다.
- 공식 일자별 종가는 **KRX 정보데이터시스템(KDM, data.krx.co.kr)** 에서 조회한다.

### 2.2 가격 개념별 정리

| 개념 | 정의 | 용도 |
|---|---|---|
| 종가(공식) | T일 정규장 15:30 최종가격 | 익일 기준가, 공시·상장 업무, 지수, 시가총액 |
| 기준가 | T+1일 기준가 = T일 정규장 종가(호가단위 미달 시 올림 조정) | 가격제한폭(±30%), 전일대비 등락 계산 |
| 시간외 종가매매 가격 | T일 종가로 체결(15:40~16:00) | 종가 체결 수요 |
| 애프터마켓 최종가 | T일 20:00 직전 마지막 체결가 | 참고 시세일 뿐 기준가·공식 종가 아님 |
| NXT 종가 | 넥스트레이드 20:00 최종가 | 참고 시세, 기준가에 반영하지 않음 |

### 2.3 핵심 원칙

1. **익일 기준가는 오직 KRX 정규장 종가로 정한다.** 이는 2025-03 넥스트레이드(NXT) 출범 때부터 적용된 원칙("전일 NXT 종가와 관계없이 KRX 종가가 익일 기준가")이며, KRX 애프터마켓에도 같은 원칙이 적용된다.
2. **애프터마켓의 가격제한폭은 T일 기준가(T-1일 종가) 기준이다.** T일 정규장 종가 기준이 아니므로 T일 애프터마켓 등락률은 "T-1일 종가 대비"로 산정된다.
3. 따라서 T일 애프터마켓에서 발생한 가격 변동은 T+1일 기준가에 반영되지 않으며, T+1일 개장 시 전일대비 등락은 다시 T일 정규장 종가를 기준으로 계산된다.

예시 (A종목)

| 시점 | 가격 | 비고 |
|---|---|---|
| T-1일 정규장 종가 | 10,000 | T일 기준가 |
| T일 정규장 종가(15:30) | 10,500 | **T일 공식 종가**, T+1일 기준가 |
| T일 애프터마켓 최종가(20:00) | 11,000 | 전일대비 +10.0%(10,000 기준) 로 표시됨 |
| T+1일 09:00 전 전일대비 | 0.0% | 기준가 10,500 기준으로 재설정 |

포털·일부 HTS는 T일 "종가"를 11,000으로 표시하지만 공식 종가는 10,500이다.

## 3. 증권사·시세 조회 서비스의 처리 방식

### 3.1 현재가(시세) 표시

- **[확인]** 네이버 증권·다음 증권 등 포털은 애프터마켓 종료 시점 가격을 "종가"로 표시한다. 거래소가 이를 명시적으로 유의 대상으로 지적했다.
- **[확인]** 대부분 증권사 HTS/MTS도 현재가 화면에 20:00까지의 체결을 반영하므로, 장 마감 후 현재가 = 애프터마켓 최종가가 된다.
- **[확인]** 전일대비/등락률은 기준가(전일 정규장 종가) 대비로 표시한다. 즉 T일 저녁 화면의 등락률은 T일 정규장 종가 대비가 아니라 T-1일 종가 대비이다.
- **[확인]** KRX·NXT 복수시장 환경에서 증권사는 통합시세를 제공하며, SOR 주문은 통합시세 기준으로 유리한 시장에 배분된다. 20:00 이후 통합시세의 마지막 가격은 KRX 또는 NXT 애프터마켓 중 늦게 체결된 가격이 된다. 기준가는 어느 경우에도 KRX 정규장 종가이다.

### 3.2 일봉 차트

- **[확인]** 대부분 증권사는 KRX 시세 일봉에 16:00~20:00 체결을 모두 반영하여, 일봉 종가가 애프터마켓 최종가로 그려진다. 그 결과 차트에서 기준가격(직전 거래일 정규장 종가)을 확인하기 어려워졌다.
- **[확인]** 일부 증권사만 "정규장 거래만 반영" 설정 메뉴를 추가하도록 HTS를 업데이트했고, 다수는 미적용 상태이다(2026-09-21 보도 기준).
- **[확인]** 거래소는 회원사(증권사)에 **일봉 차트에 기준가격을 표시할 방안을 강구**하도록 요청했다.
- 영향 [확인]
  - 기준가 대비 캔들의 양봉/음봉이 뒤바뀔 수 있다.
  - 종가 기반 보조지표(이동평균, RSI, 볼린저밴드 등) 값이 공식 종가 기준 값과 달라진다.
  - 동일 종목·동일 일자에 거래소 종가와 HTS/포털 종가가 서로 다른 "두 개의 종가" 문제가 발생한다.

### 3.3 전일 종가 필드 처리

| 항목 | 일반적인 증권사 처리 |
|---|---|
| "전일종가"/"기준가" 필드 | KRX 전일 정규장 종가 [확인] |
| 전일대비·등락률 | 기준가 대비 계산 [확인] |
| 가격제한폭(상·하한가) | 기준가 ±30% [확인] |
| 장 마감 후 현재가 | 애프터마켓(또는 통합시세) 최종 체결가 [확인] |
| 일봉 종가 | 다수: 애프터마켓 최종가 / 일부: 정규장 종가 선택 가능 [확인] |
| 익일 개장 전 표시 | 기준가를 T일 정규장 종가로 교체, 전일대비 0으로 초기화 [추정] |

### 3.4 잔고·평가 관련 [추정]

- 실시간 잔고 평가금액·평가손익은 현재가 기준으로 계산하는 것이 일반적이므로, 장 마감 후 20:00까지는 애프터마켓 체결가가 평가에 반영된다.
- 공식 종가 기반 업무(일별 잔고 확정 평가, 신용·담보 평가, 반대매매 기준가, 펀드 기준가 산정 등)는 공식 종가(정규장 종가)를 사용하는 것이 원칙이나, 증권사별 배치 기준 시각과 사용 필드가 다를 수 있으므로 개별 확인이 필요하다.

## 4. 시스템 설계 시 권고 사항

시세 수집·백테스트·리포팅 시스템에서 다음을 권고한다.

1. **종가 필드 분리**: `regular_close`(공식 종가), `after_close`(KRX 애프터마켓 최종가), `nxt_close`(NXT 최종가), `base_price`(기준가)를 별도 필드로 저장한다.
2. **수익률·지표 계산**: 일간 수익률, 이동평균 등은 `regular_close` 기준으로 계산한다. 애프터마켓 가격은 별도 세션 데이터로 취급한다.
3. **데이터 출처 검증**: 포털·증권사 API의 일봉 종가가 20:00 가격인지 15:30 가격인지 2026-09-14 전후 데이터로 검증한다. 해당 일자 이후 데이터에서 KDM 공식 종가와 대조한다.
4. **기준가 검증**: `base_price(T+1) == tick_round_up(regular_close(T))` 관계를 검증 규칙으로 둔다.
5. **등락률 해석**: 애프터마켓 시간대 등락률은 T-1일 종가 대비 값임을 UI/리포트에 명시한다.
6. **세션 구분 플래그**: 체결 데이터에 세션(정규/시간외종가/애프터마켓/NXT 프리·메인·애프터) 구분 값을 둔다.
