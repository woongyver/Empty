# Obsidian 매매일지 작성·관리 방안

## 1. 목적

- 모든 매매를 **동일한 양식**으로 기록하여 감(感)이 아닌 데이터로 매매를 평가한다.
- 진입 근거·청산 사유·심리 상태를 남겨 **반복되는 실수를 식별**하고 전략을 개선한다.
- 기록 → 집계 → 복기 → 규칙 수정으로 이어지는 **피드백 루프**를 정례화한다.

## 2. 설계 원칙

| 원칙 | 내용 |
|---|---|
| 1매매 1노트 | 매매 한 건(진입~청산)을 하나의 노트로 기록한다. 분할매매도 하나의 포지션으로 묶는다. |
| 정형 데이터는 Properties | 종목·손익·R배수 등 집계 대상은 YAML Properties에 기록하고, 서술은 본문에 기록한다. |
| 링크로 연결 | 매매 노트는 일일일지·전략 노트에 `[[링크]]`로 연결하여 맥락을 보존한다. |
| 자동 집계 | 손익·승률 등은 Dataview 쿼리로 자동 산출하고 수기 계산을 하지 않는다. |
| 최소 입력 | 진입 시 필수 항목만 입력하고, 나머지는 청산·복기 시 보완한다. |

## 3. 필수 플러그인

| 플러그인 | 용도 | 비고 |
|---|---|---|
| **Templater** (커뮤니티) | 템플릿 자동 삽입, 파일명·날짜 자동 생성 | 템플릿 폴더: `99_Templates` |
| **Dataview** (커뮤니티) | 매매 데이터 집계·대시보드 | 설정에서 *Enable JavaScript Queries* 활성화 |
| **Periodic Notes** (커뮤니티) | 일일·주간 노트 생성 | 일일 → `02_Daily`, 주간 → `03_Weekly` |
| Calendar (커뮤니티, 선택) | 달력 기반 일지 탐색 | |
| Charts 또는 Tracker (선택) | 누적 손익 곡선 시각화 | |
| Properties / Bases (코어) | 속성 편집, 표 형태 조회 | Obsidian 1.9 이상은 Bases로 Dataview 일부 대체 가능 |

## 4. 볼트 폴더 구조

```
trading-journal/
├── 00_Dashboard/      대시보드 (성과 집계, 미청산 포지션)
├── 01_Trades/YYYY/    개별 매매 기록 (1매매 1노트)
├── 02_Daily/          일일 매매일지 (장전 계획·장후 복기)
├── 03_Weekly/         주간 리뷰
├── 04_Strategies/     전략(셋업) 정의서
├── 05_Review/         월간·분기 리뷰, 실수 유형 정리
├── 90_Attachments/    차트 캡처 이미지
└── 99_Templates/      템플릿
```

**파일명 규칙**

- 매매: `YYYY-MM-DD_종목명_방향` (예: `2026-10-12_삼성전자_Long`)
- 일일: `YYYY-MM-DD`, 주간: `YYYY-[W]ww` (예: `2026-W41`)
- 차트 이미지: `YYYY-MM-DD_종목명_entry.png` / `_exit.png`

## 5. 데이터 표준 (매매 노트 Properties)

| 속성 | 형식 | 설명 |
|---|---|---|
| `type` | `trade` 고정 | 쿼리 식별자 |
| `status` | `open` / `closed` | 포지션 상태 |
| `ticker`, `market` | 텍스트 | 종목, 시장(KOSPI/KOSDAQ/US/선물 등) |
| `direction` | `long` / `short` | 방향 |
| `strategy` | `[[전략노트]]` | 사용 전략 링크 |
| `entry_date`, `exit_date` | 날짜 | 진입·청산일 |
| `entry_price`, `exit_price`, `qty` | 숫자 | 평균 진입가·청산가·수량 |
| `stop_price`, `target_price` | 숫자 | 최초 손절가·목표가 |
| `fee` | 숫자 | 수수료+세금 합계 |
| `pnl` | 숫자 | 실현 손익(비용 차감 후) |
| `r_multiple` | 숫자 | 손익 ÷ 최초 리스크 |
| `grade` | `A`~`D` | 계획 준수도 평가 |
| `mistakes` | 목록 | 실수 태그 (예: `추격매수`, `손절지연`) |
| `emotion` | 목록 | 진입 시 심리 (예: `조급`, `확신`, `FOMO`) |

> 손익·R배수는 템플릿의 계산식 섹션(Dataview 인라인)으로 확인 후 Properties에 확정값을 기입한다. 확정값이 있어야 대시보드 집계가 안정적이다.

## 6. 운영 프로세스

### 6.1 일일 루틴

| 시점 | 작업 | 소요 |
|---|---|---|
| 장 시작 전 | 일일 노트 생성 → 시장 상황, 관심 종목, 매매 계획(진입·손절·목표가) 작성 | 10분 |
| 진입 직후 | 매매 노트 생성(템플릿) → 필수 항목(종목·방향·진입가·손절가·근거) 입력, 진입 차트 캡처 | 2분 |
| 청산 직후 | 청산가·손익 입력, `status: closed` 변경, 청산 사유·차트 기록 | 3분 |
| 장 마감 후 | 일일 노트 복기 섹션 작성, 각 매매 `grade`·`mistakes` 평가 | 15분 |

### 6.2 주간 리뷰 (매주 주말)

1. 주간 노트 생성 → 대시보드 쿼리로 주간 손익·승률·평균 R 확인
2. 최고·최악 매매 각 1건 선정, 원인 분석
3. 반복된 실수 태그 확인 → 다음 주 **개선 과제 1~2개** 지정

### 6.3 월간·분기 리뷰

1. 전략별 성과(승률, 기대값, 평균 R) 비교 → 저성과 전략은 중단·수정 검토
2. 실수 유형 빈도 및 해당 손실액 집계 → 매매 규칙(`04_Strategies`) 개정
3. 리뷰 결과를 `05_Review/YYYY-MM 월간리뷰.md`로 저장

## 7. 핵심 성과 지표 (KPI)

| 지표 | 산식 | 관리 기준(예시) |
|---|---|---|
| 승률 | 수익 매매 수 ÷ 전체 청산 매매 수 | 전략별로 별도 관리 |
| 손익비 | 평균 수익 ÷ 평균 손실 | 1.5 이상 |
| 기대값 | 승률×평균수익 − 패률×평균손실 | 양(+)의 값 유지 |
| 평균 R | R배수 평균 | 0.3R 이상 |
| 계획 준수율 | grade A·B 비율 | 80% 이상 |
| 실수 비용 | `mistakes`가 있는 매매의 손실 합계 | 매월 감소 추세 |

## 8. 백업·보안·동기화

- **동기화**: Obsidian Sync(종단 간 암호화) 또는 Git(Obsidian Git 플러그인)으로 PC·모바일을 동기화한다.
- **Git 사용 시**: 계좌번호·잔고 등 민감 정보는 기록하지 않거나 비공개 저장소만 사용한다. `.obsidian/workspace*.json`은 `.gitignore`에 등록한다.
- **백업**: 월 1회 볼트 전체를 압축하여 별도 저장소에 보관한다.
- **증권사 데이터 대사**: 월말에 증권사 체결내역과 일지 손익 합계를 대조하여 누락·오기를 정정한다.

## 9. 단계별 도입 계획

| 단계 | 기간 | 내용 |
|---|---|---|
| 1단계 구축 | 1주 | 볼트 생성, 플러그인 설치, 템플릿·대시보드 배치, 전략 노트 2~3개 작성 |
| 2단계 정착 | 4주 | 모든 매매 기록, 일일 루틴 준수, 템플릿 항목 조정 |
| 3단계 분석 | 2~3개월 | 매매 50건 이상 누적 후 전략별 KPI 분석, 규칙 개정 |
| 4단계 고도화 | 이후 | 증권사 체결내역 CSV 자동 변환 스크립트, 누적 손익 차트, 태그 체계 정비 |

## 10. 이 폴더의 사용법

1. `trading-journal` 폴더를 Obsidian에서 **Open folder as vault**로 연다.
2. 3장의 플러그인을 설치하고 Templater 템플릿 폴더를 `99_Templates`로 지정한다.
3. Templater 설정의 *Folder Templates*에 다음을 등록한다.
   - `01_Trades` → `99_Templates/매매기록.md`
   - `02_Daily` → `99_Templates/일일일지.md`
   - `03_Weekly` → `99_Templates/주간리뷰.md`
   - `04_Strategies` → `99_Templates/전략.md`
4. `00_Dashboard/매매대시보드.md`를 즐겨찾기(Bookmark)에 고정한다.
5. 예시 노트(`01_Trades/2026/…`, `04_Strategies/…`)를 참고한 뒤 삭제하거나 수정하여 사용한다.
